# راح — نظام إدارة المديونيات والدائنين

تشغيل محلي:

```bash
npm install
npm run dev
```

افتراضيًا يعمل التطبيق على المنفذ 3001:

http://localhost:3001

الميزات الجديدة:
- حذف وتعديل السجلات مباشرة من لوحة التحكم
- صفحة تقارير مع ملخص ومقاييس
- تصدير البيانات إلى CSV
- لوحة عرض احترافية بألوان سوداء وذهبية
- شعار مخصص في الأعلى


تسجيل الدخول: اسم المستخدم `hazem`، كلمة المرور `1987taggeD`.

وظائف:
- عرض القوائم: مديون (أدينهم) ودائن (يدينون لي)
- إضافة شخص جديد (مطلوب تسجيل دخول كمدير)
